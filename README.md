# TaskPilot👨‍🎓

## 👋Project Overview
Employee Management System

Employee Management System is a full-stack web application designed to simplify and streamline employee information management and administrative operations. The application is developed using Java, Spring Boot, React.js, and MySQL, following a client-server architecture. It provides a centralized platform to manage employee records, departments, employee details, and organizational information. The system allows administrators to add, update, delete, search, and manage employee records efficiently through a responsive user interface. It uses Spring Boot REST APIs, Spring Data JPA, and Hibernate for backend development and database operations, with Spring Security and JWT authentication for secure access and role-based authorization. The application focuses on scalability, security, maintainability, and efficient data management.

## Features💖
- Secure Authentication & Authorization
- Different Access Levels
- Complete Task Management
- Task Progress Tracking
- Real-Time Updates
- Photo/File Upload Support
- Task Analytics and Chart Visualization
- Responsive Dashboar
- Download Task Reports Functionality

## Architecture⚙️
### 🥇Frontend 
- Built using ReactJS and styled with TailwindCSS.
- It provides the user interface and handles all user interactions.
### 🥈Backend  
- Developed using java and Spring boot.
- It manages business logic, authentication, and API handling.
### 🥉Database 
- The application uses MongoDB as its primary database.

## Installation 📝
1️⃣ Clone the repository : \
`git clone https://github.com/Ajinkya-Anap/Task-pilot.git` \
\
2️⃣ Install the dependencies for the backend : \
`cd Task-pilot/backend && npm install` \
\
3️⃣ Install the dependencies for the frontend : \
`cd ../frontend/Task-Manager && npm install` \
\
4️⃣ Configure the environment variables by creating a `.env` file based on the provided templates in the `backend` and `frontend` directories. \
\
5️⃣ Start the backend server : \
`npm start` \
\
6️⃣ Start the frontend development server : \
`npm start` \
\
7️⃣ Access the application at `http://localhost:3000`.
